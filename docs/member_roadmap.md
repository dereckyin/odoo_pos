# 會員進階能力優先級（釐清備忘）

以下為與現有「主檔＋點數＋等級＋折價券」相比的 **擴充候選**，實作順序應由產品／營運決定；本文件僅列出技術向度供排程參考。

| 優先級建議 | 項目 | 說明 |
|------------|------|------|
| P1 | **自動升降級** | 訂單入帳後依 `MemberLevel.min_spend`／`min_points` 重算 `Member.level_id`；需定義「只升不降」或週期重算等規則。 |
| P2 | **點數過期** | `PointTransaction.expires_at` 已有欄位；需批次 job、FIFO 扣點與 UI 呈現剩餘效期。 |
| P3 | **儲值／禮券** | 牽涉金流與會計科目，建議獨立子帳戶模型，與現有 `Coupon` 分流。 |
| P4 | **外部綁定（LINE 等）** | OAuth 綁定、LINE Points 或訊息推播屬整合專案，非單一 API 可涵蓋。 |
| P5 | **分群／RFM／生日自動禮** | 報表或排程行銷，需資料倉儲或離線計算 pipeline。 |

現階段 **不重構** 既有會員 API；上表可作為 backlog 分類標籤使用。
