## 完成摘要

### 前端 — `apps/admin/` (Vue 3 + Vite + TypeScript)

**基礎架構：**
- Vite + Vue 3 + TypeScript 專案骨架，含 `@` path alias
- Ant Design Vue 全域引入 + 繁體中文語系
- Pinia auth store + Axios JWT interceptor（含 token refresh）
- Vue Router 4 搭配 navigation guard 驗證登入狀態
- 左側導航 + 頂部列 + 麵包屑的 `AppLayout`

**頁面（共 17 個 view）：**

| 模組 | 頁面 | 功能 |
|------|------|------|
| **產品管理** | `ProductListView` | 搜尋、分類篩選、上架狀態篩選、上下架切換、刪除 |
| | `ProductFormView` | 新增/編輯商品（含條碼動態增刪、圖片上傳） |
| | `CategoryListView` | 分類 CRUD（modal 表單、排序、顏色） |
| | `ProductImportView` | CSV 拖曳上傳匯入 |
| **行銷方案** | `PromotionListView` | 活動列表、狀態篩選（進行中/排程中/已結束）、啟停用 |
| | `PromotionFormView` | 策略選擇 + 動態參數表單 + 適用範圍選擇器 |
| **優惠券** | `CouponListView` / `CouponFormView` | 優惠券列表 + 新增 |
| **會員** | `MemberListView` / `MemberDetailView` / `MemberLevelView` | 會員搜尋、詳情、等級管理 |
| **庫存** | `InventoryLevelView` / `TransferListView` | 庫存水位 + 安全庫存警示 |
| **門店帳號** | `StoreListView` / `UserListView` | 門店 CRUD、使用者 CRUD（含角色、密碼重設） |
| **訂單報表** | `OrderListView` / `OrderDetailView` / `ReportsView` | 訂單查詢、明細、營收統計 |

### 後端 — FastAPI API 補強

| 新增/修改 | 檔案 | 內容 |
|-----------|------|------|
| 新增 | `auth.py` → `POST /auth/admin-login` | 管理後台專用登入（不需 terminal_code，限 admin/manager） |
| 新增 | `uploads.py` → `POST /uploads/images` | 圖片上傳端點（存至 `uploads/` 目錄） |
| 新增 | `users.py` → CRUD `/users` | 使用者管理（列表、新增、更新、軟刪除） |
| 新增 | `reports.py` → `/reports/sales-summary` + `/reports/top-products` | 銷售報表聚合查詢 |
| 修改 | `products.py` | `GET /products` 新增 `is_active` 篩選參數 |
| 修改 | `main.py` | 掛載 `/uploads` 靜態檔案服務 |
